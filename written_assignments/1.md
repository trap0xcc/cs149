      arithmetic intensity so the computation performed for each element. The
      read latency is certain to be 50 cycles because of the cache miss, the
      flops for the math would have latency of 10 cycles and the final write
      would have a latency of 0 cycles. So this computation is bottlenecked by
      memory read latency. Having an additional execution context helps since
      most of the time the floating point unit is not doing any work and is
      waiting on memory.
